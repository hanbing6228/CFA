## 阶段
### 基础 Sprint  2026-07-22 → 2026-08-11  (考前 121~101 天)
只做题+错了看逐选项解析, 不读 curriculum。每天 3 新题 + 到期复习。习惯优先: never miss twice, 每次先做1题起步。

### 百日冲刺  2026-08-12 → 2026-10-08  (考前 100~43 天)
错题回炉为主, A档科目加量。每2周一次 mini-mock (20题), 按错因分类(概念/计算/陷阱/时间)驱动下周额度。

### 冲刺包  2026-10-09 → 2026-11-05  (考前 42~15 天)
高频考点题集 + 每周 mock + 框架图。retention 自动爬坡至0.88。B/C档只保'已会的', 不再开新LOS。

### 压缩期  2026-11-06 → 2026-11-20  (考前 14~0 天)
工具自动停新题。只做到期复习+🔴LOS+框架图过一遍。每张卡考前至少再见一次(调度器保证)。

## 换挡阈值 (触发即执行, 不讨论)
- 高权重科目连续两次 mini-mock <55% → 该科加额度 + 补正规题库原题
- 每日复习量超时间预算 → retention.base 下调 0.02 或砍 C 档 LOS
- 连续14天完成率 <70% → 新题额度减半, 先救习惯再救进度
- 搭工具/美化工具超过2个周末 → 立即停手, 工具已经够用了
